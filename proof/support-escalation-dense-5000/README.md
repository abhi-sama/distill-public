# Open-data run: dense assigned-language support-escalation model

A support-escalation decision model built end to end with local open-weight models. It is the
repository's headline run; `proof/RESULTS.md` has every number, regenerated by
`python proof/summarize.py`.

- **Synthesis** is pinned to the dense local `gemma4:31b-nvfp4` model (`ollama-gemma-dense`).
  The target language is assigned before each call on a deterministic schedule (39% English,
  then the multilingual tail), because left to choose, the model writes mostly English.
- **Labelling** uses the two local Ollama labellers, `ollama-qwen` and `ollama-gemma`.
  `distill-usage.jsonl` records every call; no hosted teacher or API key was used.
- All 5,000 requested training states and 150 held-out states were generated. After MinHash
  dedupe, 4,820 training states remain (3.6% removed) and 150 held-out states remain. The
  retained corpus covers 20 languages and is 38.4% English; no assigned language was declared
  unavailable. `synthesis-stats.json` has the exact language and length distributions.
- Synthesis writes each completed chunk to a progress file and resumes from it. A response that
  declares inability but also supplies text is dropped and counted as unavailable, and local
  request timeouts are retried.
- The first label pass had one malformed labeller-A batch (items 661--670); `label-retry.log`
  shows the resumable retry completing those ten rows. All 4,970 rows were then labelled before
  training.

## Two measurements, and only one is comparable

- `eval-report/`: the model on its own generated gold set (98.04%, 408 answers) and held-out
  set. It is in-distribution, so it is **not comparable** with any other result.
- `eval-on-withheld-items/`: the fair measurement. It scores the model on a withheld set of
  390 gold and 450 held-out answers that a hosted model wrote and the local labellers labelled
  (not published). Its 94.62% gold accuracy is 5.13 points behind a hosted-model reference's
  99.74% on the same answers, which is 0.13 points outside the five-point allowance. Held-out
  ECE is 0.039 and the local share at tau is 54.2%. The comparable gate is **not met**.

The corpus, labels, question spec and model weights are not published. `train.log`,
`eval.log` and the other logs are the unedited stage output, except that `eval.log` has a
machine path shortened.

Both eval folders were written by an earlier `distill eval` that always required a hosted
reference, so their `REPORT.md` and `metrics.json` say "NOT READY: ... baseline was not
measured" and show an empty reference column. Current `distill eval` reports "no reference
measured" instead; the fixed-item verdict above is computed in `proof/summarize.py`.
